# Student Performance Data Analysis

## Project Overview
This project focuses on analyzing student academic performance using Python. It explores student information and exam scores to understand patterns in mathematics, reading, and writing performance.

## Dataset
The dataset contains 1,000 student records with the following 8 columns:

- Gender
- Race/Ethnicity
- Parental Level of Education
- Lunch
- Test Preparation Course
- Math Score
- Reading Score
- Writing Score

## Technologies Used
- Python
- Pandas
- NumPy
- Jupyter Notebook

## Tasks Performed
- Loaded and explored the dataset.
- Checked dataset shape and column information.
- Analyzed data types.
- Checked missing values and duplicate records.
- Generated descriptive statistics.
- Explored student examination scores.

## How to Run
1. Clone this repository.
2. Install the required libraries:
   `pip install pandas numpy jupyter`
3. Open Jupyter Notebook:
   `jupyter notebook`
4. Open `Student_Performance_Data_Analysis.ipynb`.
5. Run all cells.

To practice data cleaning, exploratory data analysis (EDA), and statistical analysis using Python.
